## 研究方向

- 数论与分析：无理性、特殊常数、素数与多项式。
- 组合数学与概率：幻方、离散结构与概率模型。
- 算法与复杂度：3SUM、近似算法与平均敏感度。
- 形式化数学：Lean、Mathlib、证明依赖与可复现验证。

各课题的进展和验证范围以对应仓库中的证据为准。实验观察、数学论证、形式化验证与论文发表分别记录。
